# Comunicar un problema

Contactar con el interlocutor de IDC Games de vuestra integración por un canal privado para vulnerabilidades o credenciales expuestas. No adjuntar claves, tokens de jugadores, datos personales ni logs sin revisar en issues públicos. Este repositorio no proporciona un nuevo buzón de seguridad. Las incidencias de integración sin datos sensibles pueden reportarse por GitHub.
